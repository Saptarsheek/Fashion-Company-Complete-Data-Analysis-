# Fashion-Company-Complete-Data-Analysis-

# Fashion Companies Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a dataset of global fashion companies to understand patterns in company performance, market dominance, revenue trends, and industry characteristics. The dataset used for this project was sourced from a popular Kaggle dataset.
The goal of this analysis is to explore how different factors such as company age, revenue, retail store presence, country of origin, and fashion style influence the behavior and performance of fashion companies.
1.Dataset
The dataset contains information about various fashion companies, including:
* Company name
* Founding year
* Fashion style
* Revenue and total revenue
* Number of company-operated retail stores
* Country of origin
* Years of revenue data
The dataset required data cleaning and preprocessing before performing the analysis.

2.Technologies Used
* Python
* Pandas – Data manipulation and analysis
* NumPy – Numerical operations
* Seaborn – Statistical data visualization
* Matplotlib – Data plotting and charts
* Jupyter Notebook – Development environment

# Data Preprocessing
The following preprocessing steps were performed:
* Handling missing values
* Extracting the year from a text column
* Creating a company_age feature from founding year
* Cleaning categorical values (e.g., fashion style formatting)
* Splitting country_of_origin into a separate country column

# Key Analysis Questions
The project answers several analytical questions:
1. Which fashion company has the most retail stores?
2. Which companies ,dominate the market based on revenue?
3. Do older companies generate more revenue?
4. Which fashion style dominates the industry?
5. Which country has the oldest fashion companies?
6. How has revenue progressed over time in the fashion industry?
7. What is the correlation between revenue, retail stores, company age, and year?

# Visualizations
The project includes multiple visualizations such as:
* Bar charts for company retail store comparisons
* Bar charts showing top fashion companies by revenue
* Scatter plots for company age vs retail stores
* Pie charts showing fashion style distribution
* Box plots for company age distribution by country
* Line charts for revenue trends over time
* Correlation heatmaps between key business variables
These visualizations help uncover patterns and relationships within the fashion industry dataset.

# Key Insights
Some insights from the analysis include:
* Certain companies dominate the market with significantly higher revenues.
* Companies with more retail stores tend to generate higher revenue.
* Some countries have much older fashion brands compared to others.
* The dataset reveals industry trends and revenue progression across years.
